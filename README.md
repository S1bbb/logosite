# Лендинг логопеда

Личный сайт учителя-логопеда Ольги Владимировны Соколовой. Одна страница с шестью разделами: приветствие, родителям, коллегам, представление опыта работы, повышение квалификации и контакты.

Стек: HTML, CSS, TypeScript и Vite. Сайт собирается в статические файлы, без обязательного сервера или привязки к хостингу.

## Требования

- Node.js 24 (версия указана в `.nvmrc` и `package.json`).
- npm и Git.

## Работа с проектом

Из папки проекта:

```sh
npm ci
npm run dev
```

Открой адрес, который покажет терминал, обычно http://127.0.0.1:5173.
Остановить сервер: `Ctrl+C`. После первой установки повторять `npm ci` нужно при изменении зависимостей или на новом компьютере.

В PowerShell при блокировке `npm.ps1` используй `npm.cmd` вместо `npm`; менять политику выполнения не требуется.

```sh
npm run check
npm run build
npm run preview
```

`check` проверяет TypeScript, `build` проверяет типы и собирает сайт в `dist/`, `preview` открывает локальный сервер готовой сборки.

Перед запуском и сборкой автоматически выполняется `prepare:content`: подготовка пятнадцати выбранных материалов из `materials/` и копирование нужных изображений и аудиозаписей. Сами презентации для сайта находятся в `public/downloads/`.

## Структура

- `index.html` — разметка страницы и метаданные.
- `src/style.css` — стили.
- `src/main.ts` — мобильное меню, подсветка разделов, окно чтения статей и управление аудио.
- `src/article.css` — оформление материалов для чтения.
- `scripts/prepare-content.mjs` — подготовка выбранных статей и вложений.
- `public/` — файлы, которые копируются в сборку без обработки.
- `docs/brief.md` — заготовка для будущего ТЗ.
- [DESIGN.md](DESIGN.md) — предоставленная дизайн-система, по которой оформлен лендинг.
- [docs/content-sources.md](docs/content-sources.md) — источники текстов, выбор материалов и поведение страницы.
- [materials/README.md](materials/README.md) — проверенные материалы из `input/`: документы в Markdown, изображения, PDF-презентации и аудиозаписи.

## Git

Основная ветка — `main`. Репозиторий пока локальный; удалённый репозиторий подключим позже.

```sh
git status
git add .
git commit -m "Describe the change"
```

`node_modules`, `dist`, локальные настройки хостингов и `.env` исключены из Git. `package-lock.json` хранится в репозитории для воспроизводимой установки.
Переменные с префиксом `VITE_` попадают в браузер: секретные ключи в них хранить нельзя.

## Публикация позже

Проект подготовлен к статическому хостингу. Для Vercel выбери пресет Vite, команду сборки `npm run build`, папку результата `dist` и Node.js 24. Для других хостингов с поддержкой статических сайтов используются та же команда сборки и папка `dist`.

При ручной загрузке публикуется содержимое `dist/` после сборки. Текущие URL рассчитаны на корень домена. Для размещения в подпапке нужно адаптировать `base` Vite и абсолютные пути к материалам.

Удалённый репозиторий, аккаунты хостингов и домен пока не подключены. Кнопка «Написать письмо» открывает почтовое приложение через `mailto:`.

Документация: [Vite](https://vite.dev/guide/), [публикация статического сайта](https://vite.dev/guide/static-deploy.html).
