# Содержание лендинга

На странице шесть разделов. Тексты сокращены и отредактированы по предоставленным материалам без добавления стажа, отзывов, стоимости занятий или обещаний результата.

- Приветствие и образование: `materials/documents/greeting.md`. Кнопка «Читать полное приветствие» открывает весь текст исходного файла «Приветствие.docx» в окне чтения.

- Представление опыта: две презентации из `materials/presentations/` и четыре аудиозаписи к теме птиц.
- Галерея рабочих листов в разделе опыта: все три исходных изображения из `materials/documents/ai-worksheets.md`, извлечённые из файла «Соколова О.В._Представление опыта работы_Рабочие листы_ИИ.docx». Подпись указывает на создание с помощью ИИ; изображения можно открыть целиком.
- Логоритмические песенки в разделе опыта: `materials/documents/rhythmic-songs.md`. Подборка открывается в окне чтения; сохранены тексты, движения, имена авторов, библиография и ссылки. Названия режимных моментов оформлены как заголовки, таблицы получили подписи колонок.
- Квалификация: девять выбранных программ из `materials/documents/qualifications.md`, включая пункты 13, 20 и 21 исходного Word-документа; названия организаций приведены в читаемом виде. Регистрационные номера документов на страницу не выводятся.
- Контакты: `materials/documents/contacts.md`, местоположение из приветствия.

Фотография с пособиями для пересказа сказки «Теремок» перенесена из приветствия в раздел опыта работы. ## Подготовка материалов

`npm run prepare:content` собирает девять статических страниц для чтения из выбранных Markdown и копирует только нужные изображения и аудио в `public/`. Команда автоматически запускается перед `dev` и `build`. Статьи открываются в диалоге поверх лендинга; без JavaScript остаются доступны отдельными страницами.

Иллюстрации из статей о семье и загадках опущены в версии для сайта. Текстовые материалы сохранены с библиографией. OCR-черновики не используются.

В версии презентации о фонематическом слухе для сайта оставлены слайды 1, 2, 3, 4, 6, 7, 9, 11, 13, 17, 19, 20. Страницы с описаниями отсутствующих видео, именами детей и сведениями об отдельных воспитанниках не включены. Исходная презентация на 20 страниц сохранена в `materials/`.

## Поведение страницы

- Обычные якорные ссылки и CSS `scroll-behavior` обеспечивают плавную навигацию, включая прямые ссылки на разделы. При `prefers-reduced-motion` прокрутка мгновенная.
- Шапка фиксируется при прокрутке. При ширине до 1100 пикселей, включая iPad в портретной ориентации, навигация раскрывается кнопкой «Меню», закрывается после перехода и по Escape.
- Отступ якорного перехода совпадает с фактической высотой шапки и обновляется при изменении окна. Граница фона раздела располагается непосредственно под шапкой.
- На широком экране компьютера основная часть каждого раздела после приветствия занимает не меньше доступной высоты экрана. Это правило включается при ширине от 1101 пикселя, соотношении сторон от 4:3 и управлении мышью. На планшетах, телефонах и высоких портретных окнах разделы идут обычным потоком от верхнего края, без пустых полноэкранных полей. До 820 пикселей основные текстовые колонки складываются в одну. На сенсорном экране высота текстовых ссылок составляет не меньше 44 пикселей.
- Диалог статьи закрывается кнопкой, по Escape или нажатию на фон. Фокус возвращается к исходной ссылке.
- Одновременно воспроизводится одна аудиозапись.
- Почта открывает почтовое приложение через `mailto:`. Форма отправки и внешние сервисы не подключены.
