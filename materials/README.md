# Материалы для сайта логопеда

Подготовлены из папки `input/` 18 октября 2026 года. Оригиналы сохранены без изменений.

Состав: 19 документов в Markdown, 77 извлечённых изображений, 2 PDF-презентации на 20 и 7 страниц и 4 аудиозаписи из презентации про перелётных птиц. Эта папка — рабочие материалы проекта; она не подключена к публичному сайту.

## Результат проверки

- Все 21 исходных файла прочитаны: проверены контрольные суммы ZIP, XML и внутренние ссылки на вложения. Ошибок структуры не обнаружено.
- Сверка текстовых абзацев исходных Word-документов с Markdown не выявила пропусков. Сохранены 14 таблиц, ссылки и картинки; оформление страниц Word в Markdown не переносится.
- Все 100 изображений внутри Word и PowerPoint декодируются. В рабочие Markdown вынесены 77 изображений Word; изображения слайдов сохранены в PDF.
- Обе презентации открыты штатным API PowerPoint и экспортированы в PDF. PDF повторно открыты, число страниц совпадает с числом слайдов; просмотрены изображения всех 27 страниц.
- Все 4 аудиозаписи распознаны как AAC и полностью декодированы FFmpeg без ошибок. Звук хранится отдельно: экспорт в PDF не сохраняет воспроизведение аудио.
- Ссылки на внешние сайты сохранены; доступность YouTube, VK и других внешних ресурсов не проверялась.

## Особенности материалов

- Часть памяток и рабочих листов состоит из картинок. Они сохранены в Markdown как изображения. Для пяти документов добавлен отдельный раздел с черновым распознаванием текста; OCR требует сверки, особенно на мелких подписях.
- Строка «Нужно заново собрать.» в подборке логоритмических песенок относится к песне про пирамидку и сохранена как часть текста песни.
- В презентации о фонематическом слухе есть страницы с описаниями видео. Самих видео нет в исходном файле: на слайде 5 прямо указано, что они удалены из презентации. Это свойство исходника, а не потеря при экспорте.
- Материалов много для библиотеки родителям и коллегам. Для будущего лендинга в первую очередь пригодятся приветствие, контакты и сведения о квалификации; выбор остальных разделов остаётся за будущим ТЗ.

## Структура папки

- `documents/` — текстовые версии Word с относительными ссылками на картинки.
- `assets/` — извлечённые изображения, разложенные по документам.
- `presentations/` — PDF и папка аудиозаписей.
- `manifest.json` — соответствие оригиналов готовым файлам и контрольные суммы исходников.

Изображения и Markdown нужно переносить вместе, сохраняя структуру папок.
